# Design Context

## Users

Developers using this personal T3 Code fork for daily work with coding agents. Keep projects, threads, source control, and the composer easy to scan during long sessions.

## Brand Personality

Colorful, considered, professional. The approved direction is **Night Owl studio**, inspired by the editor palette: deep navy surfaces, cyan actions, lavender selections, and restrained amber highlights.

## Design Principles

- Make the interface feel like a coding workspace, with clear panel boundaries and compact toolbars.
- Give color a purpose: cyan for primary actions and focus, lavender for selection, amber for highlights and warnings.
- Keep text readable in both appearances, including secondary labels and button text.
- Preserve existing user theme choices; use Night Owl studio for fresh installs.
- Use shared semantic theme roles and component-owned styles. Avoid animated decoration and new dependencies for visual polish.

## Decisions

The user chose the studio direction over a palette-only refresh and a bolder treatment with stronger color blocks. Favor character through typography, spacing, and useful color; avoid novelty graphics or a cartoon-like interface.
